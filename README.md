# Project 11 - Infra Changes with Branching Policy

This project demonstrates a feature-branch workflow for infrastructure changes using Terraform and GitHub Pull Requests.

## Branching Strategy

- `main` - main branch
- `feature/niranjan-infra` - feature branch for infrastructure changes

## Workflow

1. Create a feature branch.
2. Make the infrastructure change.
3. Commit the change.
4. Push the feature branch to GitHub.
5. Create a Pull Request against `main`.
6. Review the Pull Request.
7. Merge the Pull Request.
